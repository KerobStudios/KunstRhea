# KunstRhea – Epochen-Quiz

Lern-Webanwendung: Bauwerke den Epochen der Architekturgeschichte zuordnen.

- 15 Epochen von der griechischen Antike bis zur zeitgenössischen Architektur
- 76 Bauwerke mit Bild, Ort, Jahr, Architekt und Erklärung
- Merkmale jeder Epoche, bei jedem Bauwerk die zutreffenden hervorgehoben
- Modi: alles abfragen, Schnellrunde (15), Lernübersicht, „Nur Bild“-Modus
- Reine statische Seite (HTML/CSS/JS), keine Abhängigkeiten

Bilder stammen von Wikimedia Commons bzw. Wikipedia; die Lizenz steht auf der jeweils verlinkten Dateiseite.

Live: https://kerobstudios.github.io/KunstRhea/
